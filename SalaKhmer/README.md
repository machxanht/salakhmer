# Khmer Buddy

Tạo app mobile về việc dạy học tiếng Khmer, cấu trúc giống ảnh đính kèm, vào lại màu sắc và font chữ cho bắt mắt theo phong cách flat, có nhân vật mascot tương tự như hình 3 có thể đổi lại thành Hanuman Khmer. Hiện app đầu tiên là hình chào mừng hình cô gái Mascot chấp tay chào , phía dưới có thanh trượt get start hiệu ứng chuyên nghiệp
