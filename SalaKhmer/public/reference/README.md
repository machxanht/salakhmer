# Reference-only handwriting proof

The files under `first-five/` are deterministic bicubic crops of the
low-resolution image linked by the project owner:

https://kimseang.wordpress.com/wp-content/uploads/2014/04/firststart.jpg?w=560&h=862

They are used only for the five-letter local UI proof (`ក ខ គ ឃ ង`). The 3×
JPEG set is retained for comparison. The UI currently uses the 5× PNG set
(530×550 each) and loads only the selected crop. The untouched downloaded
source is archived outside the public build at
`.reference/handwriting-source/firststart.jpg`.

Upscaling does not create missing detail: the 5× files reduce visible pixel
steps at mobile display size, but labels and fine arrows remain limited by the
original 560×862 JPEG.

The source licence has not been verified. Do not treat these crops as
SalaKhmer production assets, upload them to R2, or ship them in a public release
without permission or replacement by original SalaKhmer artwork.
